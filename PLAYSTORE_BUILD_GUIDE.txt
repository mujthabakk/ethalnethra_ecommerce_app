- Generate optimized bundle for Play Store

================================================================================
6. TROUBLESHOOTING
================================================================================

Issue: "Keystore file not found"
Fix: Verify ~/Documents/upload-keystore.jks exists
     Check keystore.properties path is correct

Issue: "Signing config error"
Fix: Run: flutter clean
     Then: flutter pub get
     Then: flutter build appbundle --release

Issue: "Build fails with memory error"
Fix: Already configured in android/gradle.properties
     jvmargs=-Xmx8G

Issue: Version already used on Play Store
Fix: Update pubspec.yaml version number
     Build number must always increase (the +NUMBER part)
